🧩 Seção de Recursos com Quatro Cartões

📌 Sobre o Projeto

Componente de layout em grade com quatro cartões informativos, desenvolvido com HTML5 e CSS3 como parte de um desafio do Frontend Mentor. Totalmente responsivo e com design limpo.

🎯 Funcionalidades

✅ Layout Responsivo com organização adaptável para desktop e mobile
✅ Estilo Moderno com sombreamento, cantos arredondados e cores temáticas
✅ Conteúdo Informativo com ícones e descrições claras para cada recurso
